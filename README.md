# Koreys lug'at boti (Telegram Mini App)
Railway Variables: BOT_TOKEN, WEBAPP_URL, DATA_DIR=/data, SECRET, ADMIN_IDS (yoki ADMIN_EMAILS), GOOGLE_CLIENT_ID (ixtiyoriy),
ANTHROPIC_API_KEY (tulki Kori va avto-tarjima uchun), FOX_MODEL, GOOGLE_TRANSLATE_KEY (ixtiyoriy).
Fayl formati: «koreys - tarjima» (yoki vergul bilan). Sarlavha qatorlari (OT, FE'L, SIFAT, RAVISH) so'z turini belgilaydi.
